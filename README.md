# Programa de Adjudicaturas Jaén

> [!NOTE] Nota
> 
> Este programa esta orientado a su utilización dentro de la entidad publica de la comunidad autónoma de Andalucia.

## Información

Este programa es una reeinvención de la **aplicación web** orientada a la ejecución en entornos **Windows** sin depender del navegador. Interfaz intuitiva para el usuario, diseñada especialmente para el fácil manejo de la aplicación.

Este programa recolecta un volumen específico de archivos en formato `.pdf` y los procesa. Comparando a todos los concursantes y sus provincias. Finalmente filtra a todos aquellos que han ganado una plaza en la provincia de **Jaén**.

Genera un archivo en formato `.xlsx` para una cómoda visualización en el programa de ofimática de preferencia.

El manual de uso se encuentra junto al ejecutable. Para que el usuario sepa como utilizar el programa de manera correcta.
